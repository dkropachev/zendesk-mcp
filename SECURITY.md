# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.4.x | Yes |
| 0.3.x and earlier | No |
| Earlier | No |

## Reporting

Use GitHub private vulnerability reporting for authentication bypasses, credential leakage, unsafe redirects, path traversal, write-guard bypasses, or other security defects. Do not open a public issue and do not include real Zendesk credentials or customer data.

Revoke any exposed Zendesk session or token immediately. Maintainer will acknowledge valid reports within seven days and coordinate remediation and disclosure.
